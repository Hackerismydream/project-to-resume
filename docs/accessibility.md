# Accessibility

Public documentation and visual assets should remain usable without relying on color alone.

- Give images meaningful alt text.
- Keep SVG text readable and include `<title>` and `<desc>`.
- Use descriptive link labels rather than “click here”.
- Preserve heading hierarchy and plain-text equivalents for diagrams.
- Avoid screenshots as the only source of commands or technical facts.
- Keep Chinese and English terminology consistent enough for screen-reader navigation.

The deterministic SVG in `docs/assets/` is source-controlled so text and accessibility metadata can be reviewed.
