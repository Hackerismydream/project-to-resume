# Roadmap

This roadmap lists evidence-gated improvements, not promised product capabilities.

## Near term

- Run real installed-Skill forward evaluations on fixed Java, Python Agent, RAG, fork, and weak-evidence repositories.
- Record disagreement categories between generated stories and curated gold.
- Add counterexamples where tests reveal a stronger story than README or architecture documents.
- Verify installation from a tagged release after the first release is created.

## Later, only with evidence

- Improve cross-language repository navigation when fixed cases show consistent misses.
- Add semantic duplicate evaluation when a reproducible evaluator outperforms simple exact checks.
- Add more domain overlays only when they improve story selection rather than keyword coverage.
- Publish aggregate quality results only with documented samples, models, reviewers, and severe-error definitions.

## Explicit non-goals

- Resume hosting or a private candidate database;
- Job scraping, application tracking, or automated submission;
- Fabricated metrics or JD-driven experience generation;
- Paid-service claims, user counts, or hiring outcomes without evidence;
- Executing untrusted repository code by default.
