# Decision Records

Use a lightweight decision record only for changes that alter the public Skill contract, evidence model, installation layout, or default output.

Template:

```markdown
# Decision: <title>

Status: proposed | accepted | superseded
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives
## Consequences
## Evidence and unknowns
```

Do not create decision records for routine wording or test maintenance. The goal is to preserve consequential reasoning without turning the repository into a document archive.
