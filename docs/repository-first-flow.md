# Repository-first Flow

```text
repository identity and ownership
→ role-agnostic Repository Map
→ 2–4 behavior chains
→ tests reveal failures and invariants
→ conditional history / PR / issue / upstream
→ Story Hypotheses
→ counterevidence, competition, and elimination
→ role and JD ordering
→ Claim calibration
→ copy-ready resume section
```

This page is a compact map. Operational instructions live in `SKILL.md`; detailed discovery and selection guidance live in `references/repository-discovery.md` and `references/story-selection.md`.
