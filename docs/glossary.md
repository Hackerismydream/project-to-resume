# Glossary

- **Repository Map**: A role-agnostic map of repository identity, execution surfaces, core state, inputs, outputs, side effects, tests, history, upstream, and unknowns.
- **Behavior chain**: A trace from entry through validation, state, decisions, side effects, terminal output, failure, recovery, and verification.
- **Story Hypothesis**: A falsifiable explanation of an external task or failure, the engineering decision that changes behavior, and the evidence boundary.
- **Story Card**: An internal record of a candidate story, anchors, counterevidence, ownership, claim ceiling, role signal, and unknowns.
- **Claim ceiling**: The strongest wording supported by the available source and attribution.
- **Curated gold**: A maintainer-written expected case; it is not automatically a model run.
- **Actual skill run**: A recorded execution with Skill revision, target repository revision, host Agent, model, configuration, input, output, and evaluation.
- **Upstream delta**: The behavior or code difference between a fork/derivative repository and its pinned upstream revision.
- **Independent role signal**: A capability or judgment not already proven by another project description or bullet.
