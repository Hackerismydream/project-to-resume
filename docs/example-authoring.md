# Example Authoring

Every public example should make its status obvious:

- **Copy-ready example**: demonstrates the default output contract.
- **Curated gold case**: maintainer-written expected reasoning for a fixed repository revision.
- **Actual Skill run**: captured execution with host, model, configuration, input, output, and evaluation.
- **User showcase**: authorized Before / After submitted by a user.

Do not blur these labels.

A repository-based example should include a fixed 40-character commit, target role, ownership boundary, evidence anchors, allowed Claim ceiling, and forbidden claims. The copy-ready section must contain a project title, technology line, project description, and one to five independent bullets.

Do not include private resumes, internal repository material, customer data, credentials, inferred personal details, or unverifiable hiring outcomes.
