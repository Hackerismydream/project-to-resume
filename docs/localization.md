# Localization

The default resume artifact is Chinese because the project is optimized for Chinese technical recruiting. Keep code identifiers and widely used engineering terms in their conventional form when translation would reduce precision.

When adding another language:

- Do not fork the evidence or ownership rules;
- Preserve the same default-output and Claim boundaries;
- Keep one canonical methodology source where possible;
- Test trigger descriptions and output format in that language;
- Avoid machine-translated technical claims that change strength or responsibility.
