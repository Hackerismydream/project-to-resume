# Claim Levels

| Evidence | Safe public wording | Unsafe escalation |
| --- | --- | --- |
| README or design document | Designed for, intended to | Implemented, validated, production-ready |
| Current source code | Implements, supports, distinguishes, limits | Improves success rate, guarantees reliability |
| Test source | Includes tests for, wrote regression scenarios | Tests passed, production-safe |
| Recorded test run | Passed named scenarios at a fixed revision/environment | High availability, user impact |
| Benchmark artifact | Measured A versus B under stated sample/workload | Current production effect, universal improvement |
| Release artifact | Released in named version/tag | Adopted by users, business impact |
| Usage evidence | Used under stated scope | Caused hiring or business outcomes without attribution |

Ownership is evaluated separately from technical evidence. A project can implement a capability without proving that a particular candidate personally built it.
