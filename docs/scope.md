# Scope

## In scope

- Discovering evidence-backed engineering stories from software repositories;
- Rewriting project, internship, research, and open-source experience for Chinese technical resumes;
- Applying a target role or JD after repository discovery;
- Calibrating claims, metrics, test status, releases, production effects, and personal ownership;
- Producing interview-defensible project bullets and optional follow-up questions;
- Maintaining fixed-revision examples and evaluation contracts.

## Out of scope

- General code review, debugging, architecture documentation, or repository onboarding without a resume goal;
- Full resume layout, PDF generation, ATS submission, job scraping, application tracking, or recruiting automation;
- Hosting or storing private resumes and repository contents;
- Fabricating experience to match a JD;
- Guaranteeing interviews, offers, pass rates, or hiring outcomes;
- Executing target repository code by default.

New features should strengthen the repository-to-resume decision process rather than turn the project into a broad career platform.
