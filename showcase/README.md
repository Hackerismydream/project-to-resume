# Before / After Showcase 提交规范

这个目录用于收集可公开、可复核的“项目仓库 → 简历经历”案例。它不是简历数据库，也不接收私人简历全文。

## 最小提交内容

```markdown
# 案例标题

- 公开仓库：
- 固定 commit（40 位 SHA）：
- 目标岗位：
- 原始 bullet：
- 最终采用版本：
- 个人边界：哪些部分由你负责，哪些来自团队或 upstream
- 公开范围：是否允许展示匿名案例；是否允许展示 GitHub 用户名
```

提交内容必须能够把简历表述追溯到公开仓库和固定 revision。若有 benchmark，请同时给出对应 commit、样本/负载、baseline 与结果文件；没有这些信息就不要把数字写成当前效果。

## 隐私与安全边界

不要提交：

- 私人简历全文；
- 电话、邮箱、学校、身份证明或住址；
- 公司内部仓库、未公开代码、客户数据、密钥或日志；
- 未经同意的姓名、学校、公司和求职状态；
- 无法验证的 Offer、招聘结果、通过率或用户评价。

推荐先使用 [Showcase Issue 模板](../.github/ISSUE_TEMPLATE/showcase.yml)。维护者可以要求缩小表述、移除数字或补充个人归属；这不等于认可简历效果。
