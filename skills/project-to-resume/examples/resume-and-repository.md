## 可直接粘贴的简历版本

**拼团营销交易系统｜Java 后端开发**

**技术栈：** Java、Spring Boot、Redis、MySQL、RocketMQ

**项目描述：** 负责拼团营销系统交易链路开发，覆盖活动校验、库存预占、订单创建、支付回调、成团结算及退款补偿，重点处理并发交易中的重复请求和跨组件状态一致性。

1. 将活动资格、库存预占和一人一单校验合并为 Redis Lua 原子操作，并使用数据库唯一索引兜底重复订单，缩小并发请求中的竞态窗口。
2. 设计订单、拼团与支付状态流转，为支付超时、拼团失败和退款建立逆向链路，避免异常请求停留在无法继续处理的中间状态。
3. 将业务提交与消息记录放入同一本地事务，通过幂等消费、重试和定时补偿处理消息重复与短暂失败。
4. 编写并发请求、重复回调、消息重投和补偿重跑测试用例，检查订单、库存与拼团状态的预期终态。
