# 示例：只有仓库

## 用户输入

```text
这是我的本地代码任务 Agent 仓库，帮我写成投递 Agent 工程岗位的项目经历。
```

仓库中能够看到任务循环、工具注册与参数校验、会话 checkpoint、带副作用工具的调用标识、上下文预算、终止事件和故障注入测试等实现。

## 可直接粘贴的简历版本

**面向代码仓库任务的本地 Agent Runtime｜Agent 工程**

**技术栈：** Python、Pydantic、SQLite、大语言模型、Tool Calling

**项目描述：** 面向本地代码仓库中的多步开发任务，设计 Agent 运行时，覆盖模型决策、工具执行、结果回传、状态持久化和任务终止，重点处理工具失败、进程中断、上下文膨胀及任务状态不可解释等问题。

1. 负责 Agent 任务循环与终止状态建模，串联模型调用、工具请求、结果回传和下一轮决策，并区分正常完成、工具失败、模型提供方失败与用户取消等终态。
2. 设计统一 Tool Registry，以结构化 Schema 在执行前校验工具参数，并收敛权限、超时和失败结果，避免非法调用直接进入文件与命令执行链路。
3. 采用会话 Checkpoint 持久化可恢复状态，使进程中断后的任务从最近稳定节点继续；恢复时检查带副作用工具的调用标识，不直接重放已经记录为完成的调用。
4. 为上下文设置分层选择与预算约束，优先保留任务目标、关键工具结果和未完成状态，避免完整历史持续累积挤占模型输入。
5. 围绕工具超时、参数非法、模型调用失败、循环达到上限和 Checkpoint 恢复编写故障测试用例，检查任务的预期终态和运行记录。
